Dense layout — reduce height by setting it directly on the host (#10800)

Outer document styles override shadow DOM :host styles — no custom property needed. Compare the coral outline to the baseline above.

ui5-slider — height: 2rem

ui5-slider with labels — height: 2rem

ui5-range-slider — height: 2rem

/* Outer document styles win over :host { height } in shadow DOM */
ui5-slider,
ui5-range-slider {
    height: 2rem;   /* default is 2.75rem cozy, 2rem compact */
}

::part(root-container) — background (proves the part is reachable)

ui5-slider::part(root-container) {
    background: linear-gradient(90deg, #e8f4ff 0%, #f0e8ff 100%);
    border-radius: 0.5rem;
}

::part(root-container) — reduced inline padding (orange tint shows the container)

Default side padding is 1rem. Here reduced to 0.25rem — the handle dots move closer to the edges.

Default (padding-inline: 1rem)

Reduced via ::part(root-container)

ui5-slider::part(root-container) {
    padding-inline: 0.25rem;
}

::part(progress) — custom progress bar color

ui5-slider::part(progress) {
    background: #e00;
}

::part(handle) — custom handle appearance

ui5-slider::part(handle) {
    background: #0070f2;
    border-color: #0070f2;
    border-radius: 4px;
}

::part(scale-inner) — custom track background

ui5-slider::part(scale-inner) {
    background: rgba(0, 112, 242, 0.15);
    border-radius: 4px;
}

::part(handle-icon) — custom icon color (visible when handle has an icon)

ui5-slider::part(handle-icon) {
    color: #ff6600;
}
